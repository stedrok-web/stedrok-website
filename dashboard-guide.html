How to Use the Stedrok Dashboard

This guide explains how to read the table, apply filters, and use scores as research prioritization inputs.

1. Start With Filters

Use symbol/company search, country, sector, minimum score, and rating filter to narrow the current ranked output.

2. Read Confidence Before Action

Confidence indicates data completeness and consistency behind the model score. Higher confidence generally means stronger evidence quality.

3. Compare Price, Fair Value, and Discount

Price and estimated fair value provide valuation context. Discount is the percentage gap between the two values.

4. Use Quick Ticker Insight as Context

Ticker insights summarize model stance and supporting context. They are not personal advice and should be followed by your own due diligence.

5. Export Workflow (Pro)

Pro members can export ranked rows to CSV for spreadsheet tracking, custom models, and portfolio review workflows.
